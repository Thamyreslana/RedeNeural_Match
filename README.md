Código teste para um projeto semestral universitário.
O objetivo desse projeto que foi desenvolvido com o grupo é, conectar profissionais e clientes por meio de um 'match'. 
Esse 'match' é inspirado no sistema do aplicativo de namoro "Tinder", com algumas modificações adaptadas ao contexto do projeto.

Minha contribuição do projeto, a criação da rede neural e o treinamento dela.
